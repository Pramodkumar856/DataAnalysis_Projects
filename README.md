# DataAnalysis_Projects
Customer Shopping Behavior Analysis End-to-end data analysis project using Python, MySQL, PostgreSQL, and Power BI to analyze 3,900 customer transactions. The project uncovers insights on customer segmentation, revenue trends, subscription behavior, and product performance to drive data-driven business decisions.
📈 Customer Shopping Behavior Analysis | End-to-End Data Project

Designed and executed a full data analytics pipeline analyzing 3,900+ customer transactions to identify revenue drivers, customer loyalty patterns, and product performance.

🚀 What I Did:

1-Cleaned and transformed raw data using Python
2-Handled missing values and performed feature engineering
3-Loaded cleaned data into MySQL
4-Wrote advanced SQL queries for business analysis
5-Built an interactive Power BI dashboard for visualization
6-Performed customer segmentation (New, Returning, Loyal)
📌 Key Findings:

1-Clothing category generated the highest revenue.
2-Loyal customers significantly increase lifetime value.
3-Subscription users spend more on average.
4-Shipping type impacts purchase value.
5-Discount-driven products affect profit strategy.

🚀 Business Impact
1-The insights help improve:
2-Customer retention strategies
3-Subscription growth
4-Inventory planning
5-Revenue optimization
